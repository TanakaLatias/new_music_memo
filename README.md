### 音楽をより深く楽しむためのサービス - MusicMemo -
###### 作成経緯  
ユーザーが好きな音楽のどこが好きか語ることで、音楽をより楽しむことができるサービス。  
###### 言語  
Django
###### 機能  
・Email認証つき会員登録  
・好きな曲に関する投稿作成  
・投稿に対するいいね  
・曲の好きな部分投稿作成  
・曲の好きな部分投稿に対する投票（＝いいね）
